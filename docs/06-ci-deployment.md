# 06 CI, security scanning and deployment baseline (SEC-01, INF-01, REC-06, REC-07)

## CI (`.github/workflows/ci.yml`), on every pull request and push to main

| Job | What it checks |
|---|---|
| lint | `ruff check` (incl. flake8-bandit `S` rules) and `ruff format --check` |
| test | full suite on SQLite and on PostgreSQL 16 (service container), incl. migrations == models and DB-level append-only trigger |
| dependency-scan | `pip-audit --strict` against the hash-locked `requirements-dev.lock` |
| secret-scan | `gitleaks` over full git history |
| static-analysis | `bandit` (Python SAST) and `trivy config` (Dockerfile + Kubernetes misconfiguration) |
| container | builds the image, `trivy image` (HIGH/CRITICAL, fixed only), smoke test of `/healthz` |

Scanners run from pinned container images rather than marketplace actions, to keep the
CI supply chain small. Dependabot raises weekly updates for pip, actions and the base
image. Workflow permissions are read-only.

## Build and deploy baseline

* **Dependencies** are pinned with hashes (`requirements.lock`, `requirements-dev.lock`,
  generated by `uv pip compile --generate-hashes`); the image installs with
  `--require-hashes`.
* **One OCI image** (`Dockerfile`): Python 3.12 slim, non-root UID 10001, no build tools
  in the runtime stage. Same image runs the API (`uvicorn`), the outbox worker
  (`python -m nsrdp.connectors.worker`) and migrations (`alembic upgrade head`).
* **Configuration only through environment** (`NSRDP_*`) plus the YAML policy files in
  `config/` and `contracts/` baked into the image (override by mounting). Secrets
  (database URL) come from a Kubernetes Secret, never from the repository.
* `docker-compose.yml`: local stack (PostgreSQL, migrate, API, worker).
* `deploy/k8s/`: kustomize base for GI Cloud (MeghRaj) or any conformant cluster:
  API and worker Deployments, migration Job, Service, ConfigMap, default-deny
  NetworkPolicy. Pods run non-root, read-only root filesystem, all capabilities dropped,
  seccomp `RuntimeDefault`, no service account token.

## Portability (REC-07)

No managed cloud service is required: PostgreSQL, a container runtime and (optionally)
Kubernetes are enough. Moving off GI Cloud means changing the image registry and the
Secret, not the code.
